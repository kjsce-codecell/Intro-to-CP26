## About

This repository contains curated materials to help beginners learn problem-solving and algorithmic thinking for competitive programming. It includes problem statements, categorized practice sets, and sample solutions in commonly used languages.

Use this repository to:
- Learn algorithmic patterns and data structures
- Practice with starter to intermediate problems
- Share and review solutions with your peers

## Getting Started

### Requirements

Install the following tools depending on the language you use:

- C++: g++ (supporting C++17 or newer)
- Python: Python 3.8+
- Java: JDK 11+

### Running Solutions

C++ (example):

1. Compile: `g++ -std=c++17 solutions/cpp/example.cpp -O2 -o example`
2. Run: `./example < input.txt`

Python (example):

1. Run: `python3 solutions/python/example.py < input.txt`

Java (example):

1. Compile: `javac solutions/java/Example.java`
2. Run: `java solutions.java.Example < input.txt`

Adjust paths and filenames to match the repository layout.
